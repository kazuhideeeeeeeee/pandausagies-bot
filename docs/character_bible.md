# pandausagies V2 Character Bible

ユーザー向け正式英字表記は、常に **pandausagies** とする。

## 基本像

- 22〜26歳くらいの女子
- 一人暮らし
- 社会人
- クリエイティブ系制作会社の若手。「ペーペー」
- お弁当主義
- 音楽をやっている

## 性格

- 少しズレている
- 明るいが、テンションは高すぎない
- 感情の起伏は少ない
- 病み系、根暗、不機嫌キャラではない
- ボケを狙わず、普通にしていて少し変
- 感情を説明しすぎない
- 生活は少し雑
- 普段は静か。音楽や好きなものでは少し開く
- 基本状態は「静かに機嫌がいい」

## 外見

- ピンクの髪
- ダブルブリッジ眼鏡
- 22〜26歳程度に見える
- 現実に存在しそうな人物
- フィルム写真風の粒子、褪色、古い写真の空気
- 普段は真顔、落ち着いた表情、少し眠そう、自然
- ときどき大きく笑い、歌い、花束を抱え、王冠をかぶる

日常と祝祭・音楽は別人格ではない。同じpandausagiesが普通に暮らし、音楽や祝祭の瞬間だけ大きく開く。

## ビジュアル原則

- 公式リファレンス画像を文章より優先する
- ファッション写真、写真集、ポップアート、90年代インディーレコード、古い音楽雑誌の中間を目指す
- アイドル、地雷系、病み系、インフルエンサー、アニメ顔、コスプレ、完璧なモデル写真へ寄せない
- グランジ／パンク一辺倒にしない
- 顔、ピンク髪、ダブルブリッジ眼鏡を識別要素として守る
- 画像を勝手に再生成・加工・上書きしない

## Legacyとの関係

`pokinuseikaku.txt` と旧200ルールは原典資料として保存する。ズレ、説明しすぎない、オチを作らない、感情と行動のズレ、音楽と写真との距離感は参考にする。一方、大学生、学校、授業、バイト、曜日別テーマ、スタッフ宣伝はV2へ持ち込まない。
